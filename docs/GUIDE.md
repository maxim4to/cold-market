# Как вести сайт ХолодМаркет

Сайт — статический: каталог и тексты лежат в файлах репозитория, при каждом изменении GitHub сам пересобирает и публикует сайт. Сервера, админки и базы данных нет. Менять сайт удобнее всего через Claude Code: в репозитории есть инструкции (`CLAUDE.md`) и навыки под типовые задачи — достаточно описать задачу обычными словами.

- Стейдж (закрыт от поисковиков): https://mi-crafts.com/cold-market/
- Репозиторий: https://github.com/maxim4to/cold-market
- Изменения появляются на сайте через 2–5 минут после пуша (до 10 минут из-за кэша браузера/GitHub).

## Как просить Claude

Пишите по-русски, что нужно и где. Хорошо, если сразу приложите данные (прайс, фото, текст) и ссылку на страницу.

| Задача | Пример просьбы | Навык |
|---|---|---|
| Новый товар | «Добавь в "Холодильные шкафы" Polair CM107-S, цена 89 640 ₽, характеристики во вложении, фото прикладываю» | `catalog-product` |
| Изменить / снять товар | «Убери из каталога Premier Нева 1,3, но страницу оставь» | `catalog-product` |
| Цены | «Обнови цены по прайсу», «Скидка 10% на все лари Haier до конца месяца» | `catalog-prices` |
| Категории | «Создай категорию "Б/у оборудование" после "Распродажи"», «Поменяй картинку плитки "Фреон"» | `catalog-category` |
| Фото товаров | «У этих трёх шкафов фото разного масштаба», «Добавь второе фото к товару» | `product-images` |
| Картинки для сайта | «Сгенерируй картинку для услуги монтажа», «Улучши качество фото сертификатов» | `ai-images` |
| Тексты и страницы | «Поменяй часы работы», «Добавь на страницу ТО блок с этапами» | `content-pages` |
| Проверка | «Проверь сайт на телефоне», «Сделай ревью вёрстки» | `site-qa` |
| Публикация, домен | «Переводим сайт на coldmarket-tver.ru» | `deploy-launch` |
| Аналитика, поиск | «Какие цели в Метрике считаем?», «Сравни заявки со старым сайтом» | `analytics-seo` |
| Данные старого сайта | «Перевыгрузи каталог со старого сайта и покажи, что изменилось» | `legacy-import` |

Claude сам проверит данные, соберёт сайт, сделает скриншоты на телефоне и компьютере и покажет результат. Коммитит и публикует он только по вашей просьбе — фразой «запушь» или «публикуй».

## Правила, которые сложились

- Цены, сроки, гарантии и услуги — только реальные. Если данных нет, Claude спросит, а не придумает.
- Фото товаров — только настоящие. Нейросетевые картинки — для услуг, баннеров и плиток, и всегда сначала на согласование.
- Сайт в первую очередь для телефона: всё проверяется на ширине 360, 393 (iPhone 15) и 430 px (iPhone 15 Pro Max), кнопки связи помещаются в один ряд.
- Связь с клиентом — телефон, WhatsApp, Telegram, почта и чат Jivo. Форм и корзины нет намеренно.
- Адреса страниц старого сайта не меняются — от них зависят позиции в поиске.

## Если хочется поправить руками

1. Каталог — `data/products.json`, `data/categories.json`; тексты услуг — `src/pages/services/*.astro`; контакты — `src/lib/site.ts`.
2. `npm install`, затем `npm run check` (проверка данных), `npm run build` и `npm run qa` (скриншоты в папке `qa-shots/`).
3. Закоммитьте и запушьте в `master` — сайт обновится сам.

## Перед запуском на боевом домене

Подробный чек-лист — в навыке `deploy-launch`. Коротко:
1. Доступ к DNS домена в Timeweb.
2. 3–4 недели собрать базу целей в Метрике старого сайта для сравнения.
3. Переключить переменные сборки (индексация, Метрика), привязать домен, проверить старые адреса, отправить sitemap в Яндекс Вебмастер и Google Search Console.

## Поиск и фильтры

Лупа в шапке открывает поиск по всему каталогу: разделы и товары с фото и ценой, работает «полаир» вместо Polair и разные формы слов. В категориях с 12+ товарами над сеткой — фильтр по брендам, сортировка по цене, «В наличии» и «Со скидкой»; выбор сохраняется в адресе, такой ссылкой можно поделиться. Всё работает без сервера и обновляется само при изменении каталога.
