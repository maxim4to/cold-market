# ХолодМаркет — сайт coldmarket-tver.ru

Информационный сайт-каталог компании «ХолодМаркет» (Тверь): холодильное, торговое и технологическое оборудование, монтаж, ТО, ремонт. Перенесён со старого Joomla-сайта на статический Astro. Корзины, форм и личного кабинета нет — посетитель смотрит каталог и связывается по телефону, WhatsApp, Telegram, почте или через чат Jivo.

Отвечай пользователю **по-русски**. Тексты на сайте — тоже на русском.

## Команды

```bash
npm run dev            # локальная разработка
npm run check          # проверка data/*.json (запускать после любой правки данных)
npm run images         # конвертировать новые фото из assets/products и assets/categories
npm run build          # сборка в dist/
npm run qa             # скриншоты ключевых страниц на 360/393/1366 px + проверка горизонтальной прокрутки
```

Сборка как на стейдже: `PUBLIC_NOINDEX=true BASE_PATH=/cold-market SITE_URL=https://mi-crafts.com npm run build`.
`astro preview` тоже нужно запускать с теми же `BASE_PATH`/`SITE_URL`, иначе все страницы отдадут 404.

## Устройство

- `data/products.json` (2 546 товаров), `data/categories.json` (243 категории, корень — `"/"`), `data/pages.json` (старые тексты «О компании»), `data/image-boxes.json` (рамки товара на фото, считает `scripts/build-images.mjs`). **Это источник правды каталога.** Структура полей — в навыке `catalog-product`.
- `src/pages/[...slug].astro` — все страницы категорий и товаров (URL `/<категория>.html` и `/<категория>/<товар>.html` сохранены 1:1 со старого сайта ради SEO; `build.format: 'file'`).
- `src/pages/index.astro` — главная; `services/*.astro` — страницы услуг (`ServiceLayout`, `ServiceGallery`); `kontakty.astro`, `about.astro` (`InfoLayout` + старый текст), `services.astro` — только переадресация на `/#services`.
- `src/lib/catalog.ts` — загрузка данных, дерево категорий, счётчики, `localImage`, `framedStyle`, `displayPrice`, `cleanHtml`. `src/lib/legacy-html.ts` — чистка старого HTML описаний (пустые элементы, таблицы, дубли характеристик). `src/lib/site.ts` — телефоны, адрес, часы, меню, список услуг.
- `src/layouts/Base.astro` — head/SEO/JSON-LD, шапка, мобильное меню, подвал, нижняя панель контактов на телефонах, Метрика и Jivo.
- `public/img/p/*.webp` (фото товаров 1200px), `public/img/p/t/` (превью 480px), `public/img/c/` (плитки категорий), `public/img/gen/` (картинки услуг, сгенерированные и улучшенные), `public/img/site/` (прочие картинки со старого сайта).
- `assets/generated/` — исходники сгенерированных/улучшенных картинок (полное разрешение). `assets/products/`, `assets/categories/` — исходники новых фото.
- `scraper/` — краулер и парсер старого сайта (навык `legacy-import`). `data/raw/pages.tar.xz` — архив всех HTML старого сайта.
- `.github/workflows/deploy.yml` — сборка и публикация на GitHub Pages при пуше в `master`.

## Правила работы

- **Git**: работать в текущей ветке. Коммитить и пушить только по просьбе пользователя. Если параллельно работает субагент — пушить только свои правки, чужую незаконченную работу не трогать. Сообщения коммитов — по-английски.
- **Комментарии в коде** — только для неочевидного.
- **Не выдумывать факты о компании**: цены, сроки, гарантии, услуги — только из старого сайта или со слов пользователя. Если в источнике противоречие — показать пользователю, не решать самому.
- **Перед пушем** — `npm run check`, сборка, `npm run qa` и просмотр скриншотов глазами (навык `site-qa`). Любые правки вёрстки проверять на 360, 393 и 1366 px.
- Значимые изменения внешнего вида (логотип, новые картинки, ролики) — сначала показать пользователю, ставить на сайт после «да».

## Дизайн-система

- Tailwind 4, токены в `src/styles/global.css` (`@theme`): `ink` #0b1f33, `brand` #00aeef, `brand-deep` #0077b6, `brand-night` #062a45, `ice`/`frost` (светлые фоны), `line`, `muted`. Шрифт Manrope.
- Повторно используемые классы (`btn`, `btn-primary`, `btn-wa`, `card`, `eyebrow`, `container-x`, `prose-cm`) объявлены через `@utility`. В Tailwind 4 `@apply` не видит классы из `@layer components`.
- Логотип — `src/components/LogoMark.astro` (одноцветный SVG, `currentColor`). В шапке — белый знак в сине-голубом квадрате, сдвинут на 5% вверх для оптического баланса; в подвале — белый без квадрата. Иконки — `src/components/Icon.astro`.
- Мобильные кнопки в ряд: `grid grid-cols-2` (или `-3`) с `px-3 text-[13px]` на телефоне, `sm:flex` на десктопе — так кнопки помещаются в одну строку на 360 px.

## Известные грабли (разобраны, не повторять)

- **Мобильное меню**: у шапки не должно быть `backdrop-blur`/`transform`/`filter` — они делают её контейнером для `position: fixed`, и панель меню обрезается до высоты шапки. Высота панели — `100vh` с `supports-[height:100dvh]`.
- **Jivo**: классы виджета хешированные и меняются. Кнопку поднимает над нижней панелью скрипт в `Base.astro` (ищет fixed `jdiv` у нижнего края), CSS — только запасной вариант.
- **Видео на iPhone**: в режиме энергосбережения `<video autoplay>` показывает кнопку Play. Короткие зацикленные анимации делать анимированным WebP в `<img>`/`<picture>` с запасным кадром для `prefers-reduced-motion`.
- **Фото товаров**: файлы не обрезаются. Ровный масштаб в сетке — через рамку из `data/image-boxes.json` (`framedStyle`). Водяные знаки поставщиков алгоритм рамки игнорирует.
- **Цена «1 руб.»** в данных — заглушка старого сайта, на сайте показывается «Цена по запросу» (`displayPrice`). В JSON-LD такие цены не попадают.
- **Пустые категории** (без товаров) не показываются в плитках, меню и подвале, но их страницы собираются — старые адреса должны жить.
- **Дубли характеристик**: строки описаний, повторяющие блок характеристик, убирает `legacy-html.ts` при сборке. Данные не трогаем.
- **GitHub Pages**: нет серверных 301 — переадресация только HTML-страницей с `meta refresh` (как `services.astro`). Кэш до 10 минут: пользователь может видеть старую версию.
- **Генерация картинок нейросетью** путает геометрию (лишние трубки, двери, открывающиеся в обе стороны). Всегда смотреть результат в полном размере, в промпте явно описывать физически правильную конструкцию. Фото товаров не генерировать — только реальные.
