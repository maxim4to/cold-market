# Товар в каталоге

Все товары — в `data/products.json` (массив). Страница товара собирается из него автоматически: `src/pages/[...slug].astro`.

## Поля товара

```jsonc
{
  "url": "/morozilnye-lari/lar-haier-hce150r.html", // /<категория>/<slug>.html — первый сегмент = основная категория (хлебные крошки)
  "id": 5088,                       // число, уникальное; для нового товара — max(id)+1
  "name": "Морозильный ларь HCE150R", // H1 и карточка
  "title": "Морозильный ларь HCE150R - ХолодМаркет", // <title> страницы
  "meta_description": "",           // можно пустым — описание сгенерируется из названия, цены и характеристик
  "meta_keywords": "",
  "manufacturer": "Haier",          // или null
  "product_code": null,
  "price": "21 620 руб.",           // строка как на старом сайте; "1 руб." = «Цена по запросу»
  "old_price": null,                // "25 000 руб." — показывается зачёркнутой
  "labels": ["В наличии"],          // ярлыки на карточке: "В наличии", "Sale" (выводится как «Скидка»)
  "specs": [                        // блок «Характеристики» — группы полей
    { "group": "Характеристики", "fields": [{ "name": "Охлаждаемый объем, л", "value": "150" }] },
    { "group": "Габаритные размеры", "fields": [{ "name": "Длина, мм", "value": "730" }] }
  ],
  "description_html": "<p>…</p>",  // HTML описания; при сборке чистится (legacy-html.ts)
  "description_text": "…",          // тот же текст без тегов (для JSON-LD)
  "images": [{ "full": "/img/p/lar-haier-hce150r.webp", "alt": "Морозильный ларь HCE150R" }],
  "categories": ["/morozilnye-lari.html"] // в каких категориях товар есть в списке
}
```

Поля `list_price`, `list_old_price`, `list_labels`, `availability`, `category_id`, `medium`/`thumb` у фото — наследие старого сайта; для новых товаров не нужны.

## Добавить товар

1. Уточни у пользователя: категория, название, производитель, цена (или «по запросу»), характеристики, описание, фото. **Не выдумывай** характеристики и цены.
2. Фото положи в `assets/products/<slug>.jpg` (или `<slug>-2.jpg` …) и выполни `npm run images` — появятся `public/img/p/<slug>.webp`, превью и рамка в `data/image-boxes.json` (подробнее — навык `product-images`).
3. Добавь объект в `data/products.json`. `url` — латиница в нижнем регистре через дефис, первый сегмент — существующая категория.
4. Добавь `url` товара в массив `products` нужной категории (и подкатегорий, если надо) в `data/categories.json` — порядок в массиве = порядок в каталоге.
5. `npm run check` → сборка → `npm run qa -- /<категория>.html /<url товара>` → посмотреть скриншоты.

## Изменить товар

Правь поля в `data/products.json`. Если меняется `url` — это новый адрес страницы: старый пропадёт из поиска. Без крайней нужды URL не менять; если меняешь — создай переадресацию (как `src/pages/services.astro`) и обнови ссылки в `categories.json`.

## Убрать товар

- Снять с продажи, оставив страницу (лучше для SEO): убрать `url` из `products` всех категорий — товар пропадёт из каталога, но страница останется.
- Удалить полностью: удалить объект из `products.json` и из категорий. Предупреди пользователя, что старый адрес станет 404.

## Правила

- Характеристики, которые дублируют блок `specs`, не нужно повторять в `description_html` — при сборке они всё равно вырезаются.
- Названия КАПСОМ встречаются у ~46% старых товаров; новые пиши обычным регистром.
- После правки — коммит только по просьбе пользователя.
