# Импорт со старого сайта

Пока старый сайт работает, его можно перевыгрузить. После переезда источником правды остаётся `data/*.json` — перевыгрузка затрёт ручные правки, поэтому сначала спроси пользователя и сделай дифф.

## Шаги

Скрипты — в `scraper/`, запускать с `python3 -I`. Рабочие папки держи вне репозитория (scratchpad), в репозиторий — только итоговые JSON.

1. **Краулинг**: `python3 -I scraper/crawl.py <папка>` — обходит все страницы (8 потоков, User-Agent браузера: без него сайт рвёт соединение), учитывает пагинацию категорий `?start=`, пропускает корзину (`/korzina/`, `/korzina.html`) — но не товары со словом «korzina» в адресе. Индекс — `<папка>/_index.json`. Около 2 900 страниц.
2. **Парсинг**: `python3 -I scraper/parse.py <папка> <выход>` → `products.json`, `categories.json`, `pages.json`. Проверка полноты: в выводе `listed-but-not-fetched` должно быть 0.
3. **Фото**: `python3 -I scraper/images.py <выход> <папка фото>` → `node scripts/build-images.mjs <папка фото>`.
4. Сравни с текущими `data/*.json` (количество, изменённые цены, новые/исчезнувшие товары), покажи пользователю, затем `npm run check` и сборка.
5. Сырые HTML на память — `data/raw/pages.tar.xz` (`tar -cJf`).

## Особенности старого сайта

- Цена «1 руб.» — заглушка «по запросу».
- Описания — старый HTML с мусором: пустые абзацы, отступы из `&nbsp;`, таблицы для вёрстки, `<dl>` вокруг всего описания, дублирующие заголовки «Описание», повтор характеристик. Всё это чистится **при сборке** (`src/lib/legacy-html.ts`, вызывается из `cleanHtml` в `catalog.ts`), данные не меняются. Новые правила чистки добавляй туда и проверяй на всех страницах (`dist/`), а не на одной.
- Раздел «Ремонт оборудования» в каталоге был пустым (только тексты); его содержимое перенесено на `/services/ro.html`, включая «Переделку морозильных ларей».
- На старой странице «Контакты» сломана карта, e-mail спрятан JS; `sitemap.xml` отдаёт 404.
