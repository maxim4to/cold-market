# Категории каталога

Категории — в `data/categories.json`. Дерево задаётся полем `subcategories`, корень — категория с `url: "/"` (её подкатегории = плитки «Каталог оборудования» на главной, список в мобильном меню и в подвале).

```jsonc
{
  "url": "/morozilnye-lari.html",   // адрес страницы категории
  "name": "Морозильные лари",       // H1 и название плитки
  "title": "Купить морозильные лари в Твери - ХолодМаркет",
  "meta_description": "…",           // пустое → сгенерируется
  "description_html": "",            // текст под товарами (чистится при сборке)
  "subcategories": [{ "url": "/lari-s-pryamym-steklom.html", "name": "Лари с прямым стеклом", "image": "https://coldmarket-tver.ru/…/img_categories/x.jpg" }],
  "products": ["/morozilnye-lari/…html"] // товары прямо в этой категории, в порядке показа
}
```

Картинка плитки берётся из `image` в списке `subcategories` **родителя**. Новые картинки: положить в `assets/categories/<имя>.jpg`, выполнить `npm run images`, указать `"image": "/img/c/<имя>.webp"`.

## Как это работает на сайте

- Счётчик на плитке («56 товаров») — товары категории и всех вложенных, без повторов (`productCount` в `catalog.ts`).
- Категория без товаров **не показывается** в плитках, меню и подвале, но её страница собирается (старые адреса живут). Поэтому «Ремонт оборудования» исчез из каталога — это услуга, её страница `/services/ro.html`.
- Порядок плиток = порядок в `subcategories` корня. Исключение: «Распродажа» (`SALE_URL` в `src/pages/index.astro`) всегда последняя и с диагональной ленточкой `SALE` (проп `ribbon` у `CategoryTile`).
- `/rasprodazha.html` показывает все товары своих подкатегорий прямо на странице.

## Типовые задачи

- **Новая категория**: добавить объект в `categories.json`, ссылку на неё — в `subcategories` родителя (с `name` и `image`), товары — в `products`. URL — `/<slug>.html`, латиницей.
- **Переименовать**: поменять `name` и в самой категории, и в `subcategories` родителя. URL не трогать.
- **Переместить**: убрать из `subcategories` старого родителя, добавить новому. Хлебные крошки пересчитаются сами.
- **Скрыть**: убрать из `subcategories` родителя (страница останется доступной по прямой ссылке) или убрать все товары.
- **Другая категория с ленточкой**: в `index.astro` передать `ribbon` нужной плитке; текст ленты короткий (до ~6 символов), иначе не поместится в угол.

После правок: `npm run check`, сборка, `npm run qa -- / /<категория>.html`, просмотреть скриншоты (особенно плитки на 360 px).
