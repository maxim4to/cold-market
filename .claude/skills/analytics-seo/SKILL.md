# Аналитика и SEO

## Метрика

- Счётчик `61138234` (тот же, что у старого сайта — история не теряется). Включается переменной `PUBLIC_METRIKA_ID`; на стейдже выключен. Код — в конце `src/layouts/Base.astro`: вебвизор, карта кликов, `params: { site_version: 'v2' }` для сравнения «до/после».
- Цели отправляются автоматически по атрибуту `data-goal` на любом элементе:

| Цель | Где |
|---|---|
| `click_phone` | все ссылки `tel:` |
| `click_whatsapp`, `click_telegram`, `click_email` | кнопки мессенджеров и почты |
| `click_route` | «Построить маршрут» |
| `jivo_open`, `jivo_message` | открытие чата и отправка сообщения (колбэки Jivo) |
| `search_click` | переход из поиска к найденному (с параметром `query`) — показывает, что ищут |

  Новая кнопка связи → добавь ей `data-goal` с одним из этих имён. В интерфейсе Метрики цели типа «JavaScript-событие» с теми же идентификаторами + составная цель «Контакт».
- Сравнение со старым сайтом: 4 недели до и после переезда, с поправкой на сезон (тот же период прошлого года). Конверсия в «Контакт», отказы, глубина, доля мобильных, органика Яндекса и Google. Звонки, набранные вручную с компьютера, считает только коллтрекинг (не подключён).

## SEO

- `<title>`/`description`: у категорий и товаров — из данных старого сайта, а если пусто — генерируются (`[...slug].astro`: «… — купить в Твери», цена, ключевые характеристики). У страниц услуг — прописаны в файлах.
- Canonical и OpenGraph — в `Base.astro`. При `PUBLIC_NOINDEX=true` вместо canonical ставится `noindex, nofollow`, а `robots.txt` закрывает сайт.
- JSON-LD: `Store` (адрес, телефоны, часы, координаты) на всех страницах, `BreadcrumbList`, `Product` + `Offer` (только для цен > 1 ₽), `Service` на страницах услуг.
- `sitemap.xml` — `src/pages/sitemap.xml.ts`: главная, инфостраницы, услуги, все категории и товары. Переадресации (`/services.html`) туда не включать.
- Ключевые запросы: «холодильное оборудование Тверь», «торговое оборудование Тверь», «морозильный ларь / витрина / горка / шкаф купить Тверь», «ремонт холодильного оборудования Тверь», «обслуживание холодильного оборудования», «оборудование для общепита Тверь». Уникальные вводные тексты категорий — хороший следующий шаг (тексты согласовывать с пользователем).
- Идеи, ещё не сделанные: YML-фид для Яндекс Товаров, карточки в Яндекс Бизнесе/2ГИС с единым NAP, IndexNow.
