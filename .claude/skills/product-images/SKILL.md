# Фото товаров и категорий

## Конвейер

`npm run images` = `node scripts/build-images.mjs assets`:

| Исходник | Результат |
|---|---|
| `assets/products/<имя>.jpg` | `public/img/p/<имя>.webp` (до 1200 px) и `public/img/p/t/<имя>.webp` (превью 480 px) + рамка `p/<имя>` в `data/image-boxes.json` |
| `assets/categories/<имя>.jpg` | `public/img/c/<имя>.webp` (до 640 px) + рамка `c/<имя>` |

В данных товара пиши `"full": "/img/p/<имя>.webp"`, в плитке категории — `"image": "/img/c/<имя>.webp"`.
Скрипт пропускает уже сконвертированные файлы; `FORCE=1 npm run images` пересоберёт всё и пересчитает рамки.

Фото со старого сайта лежат уже готовыми в `public/img/`. Их оригиналов в репозитории нет (≈700 МБ); если понадобятся — скачать заново `scraper/images.py` (навык `legacy-import`) и прогнать `node scripts/build-images.mjs <папка загрузки>`.

## Ровный масштаб в каталоге

Файлы **не обрезаются** — на странице товара показывается фото целиком. В сетке каталога и в плитках карточка увеличивает фото через CSS так, чтобы товар занимал 88% рамки (`framedStyle` в `src/lib/catalog.ts`, рамка из `data/image-boxes.json`).

Как считается рамка (`contentBox` в `scripts/build-images.mjs`):
1. Фото «на светлом фоне», если светлые хотя бы 3 из 4 углов. Иначе (интерьер, крупный план) рамки нет — фото показывается целиком с отступами.
2. Маска «не фона» → морфологическое «открытие» убирает тонкие линии (бледные водяные знаки поставщиков) → крупные пятна → восстановление по связности (возвращает тонкие края самого товара: ножи, решётки).
3. Для чертежей из одних линий — запасной вариант через простую обрезку полей.

Если пользователь видит неровный масштаб:
- посмотри конкретное фото и его запись в `image-boxes.json` (`x, y, w, h` — доли кадра, `a` — пропорции);
- проверь, не тёмные ли углы (тогда рамки нет);
- поправь запись вручную или исправь исходник и пересчитай. Не возвращайся к обрезке файлов — это решение отвергнуто.

## Качество

- Фото товаров **не генерировать нейросетью** — покупатель должен видеть реальную модель.
- Мелкие фото (до ~400 px) в галерее не растягиваются больше чем в 1,5 раза, поэтому выглядят небольшими, но не размытыми. Улучшить можно апскейлом Real-ESRGAN (навык `ai-images`), но на фото с текстом/шумом он даёт артефакты — результат показать пользователю.
- Проверять результат на `npm run qa -- /<категория>.html` и глазами.
