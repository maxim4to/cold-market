## 2. Целевой стек

- **Astro** (SSG). На выходе чистый статический HTML и ноль JS по умолчанию: лучший вариант для SEO и скорости. При `build.format: 'file'` можно 1:1 сохранить текущие URL вида `/about.html`, `/morozilnye-lari.html`, `/kategoriya/tovar.html`.
- **Tailwind CSS** и собственная дизайн-система. Шрифты (Manrope или Inter, кириллица) хостим сами.
- **Контент:** каталог хранится в Astro Content Collections (JSON/YAML, по файлу на товар), тексты в Markdown. Обновлять можно через git, при желании позже подключить headless CMS (Decap/Keystatic) без смены стека.
- **Изображения:** `astro:assets` / sharp: AVIF/WebP, `srcset`, lazy-load, фиксированные размеры (CLS = 0).
- **Хостинг в РФ** (быстрее для Яндекса и пользователей Твери): Yandex Cloud Object Storage + CDN, Selectel или Timeweb static, либо текущий nginx. Деплой — CI по пушу.
- **Без интерактива:** ни корзины, ни форм, ни личного кабинета. Контакт только ссылками: `tel:`, WhatsApp, Telegram, `mailto:`, «Построить маршрут» в Яндекс Картах.

## 3. Перенос контента

1. **Источник данных.** Лучше всего выгрузить базу Joomla (таблицы `#__jshopping_*`): там полное дерево категорий, все товары с характеристиками, ценами и порядком сортировки. Если доступа к БД нет — парсер по сайту с обходом пагинации (`?start=`). Прототип краулера уже работает.
2. Нормализация: дерево категорий, товары (slug, название, производитель, цена, характеристики key→value, описание, фото), привязка товара к нескольким категориям с одним каноническим URL.
3. Скачивание и дедупликация фото (`img_products/full_*`), конвертация.
4. Карта редиректов (nginx 301): всё, что исчезает (`korzina*`, `wishlist`, `/product/…` дубли, `index.php?...`, `www.`), ведёт на канонические адреса. Остальные URL сохраняются как есть.
5. Тексты: чистка «SEO-воды» в услугах, прайсы ТО и ремонта как нормальные таблицы.

## 4. Дизайн

Аудитория — B2B: владельцы магазинов, кафе, пекарен, закупщики. Им нужно быстро найти оборудование, понять, что компания надёжная, и позвонить.

- **Стиль:** «холодный» и технический. Белый и светло-ледяной фон, глубокий тёмно-синий для текста и подвала, акцент — фирменный голубой `#00aeef` (уже есть в бренде). Аккуратные карточки, много воздуха, акцент на характеристиках. Лёгкий «инейный» градиент только в hero, без «стекла» везде.
- **Шапка:** логотип, телефон крупно, WhatsApp/Telegram, «Каталог». На мобильных — закреплённая нижняя панель «Позвонить · WhatsApp · Telegram».
- **Главная:** hero («Холодильное и торговое оборудование в Твери — продажа, монтаж, сервис, 20+ лет») → плитки категорий → услуги → преимущества (склад, монтаж, гарантийный сервис, выезд по области) → бренды и сертификаты → контакты с Яндекс Картой.
- **Категория:** хлебные крошки, подкатегории, сетка товаров с ключевыми характеристиками (объём, t°, длина), «цена от».
- **Карточка:** галерея, таблица характеристик, блок «Уточнить наличие и цену» с кнопками звонка и мессенджеров, похожие товары.
- **Услуги:** отдельная посадочная страница на каждую, с прайсом и призывом позвонить.
- Доступность: контраст AA, крупные тап-зоны, корректная семантика.

## 5. Аналитика и сравнение «старый vs новый»

**Сделать до запуска (база для сравнения):**
1. Получить доступ к Метрике 61138234, Яндекс Вебмастеру и Google Search Console.
2. **Добавить цели на старый сайт уже сейчас** (одна вставка JS в шаблон Joomla): `click_phone`, `click_whatsapp`, `click_telegram`, `click_email`. Плюс включить автоматические цели Метрики (клики по телефону, e-mail, мессенджерам). Собрать 3–4 недели базы. Без этого сравнивать конверсию не с чем.
3. Снять срез: визиты, источники, отказы, глубина, время, топ входных страниц; в Вебмастере — показы, клики, CTR, средняя позиция по ключевым запросам и число страниц в индексе.

**На новом сайте:**
- Тот же счётчик 61138234, чтобы сохранить историю. Переход отмечаем примечанием в Метрике и параметром визита `site_version: "v2"`.
- Те же цели с теми же идентификаторами, плюс `click_route` (маршрут) и `view_price_table`. Отдельная составная цель «Контакт» = любой из кликов.
- Вебвизор и карта кликов остаются. Метрика грузится отложенно, чтобы не портить скорость.
- Опционально — коллтрекинг (подменный номер только для сайта: Calltouch, CoMagic, Callibri). Это единственный способ считать звонки, набранные вручную с десктопа, а не только клики по `tel:`.

**Метрики сравнения** (4 недели до и 4 недели после запуска, с поправкой на сезонность через прошлый год):
конверсия в «Контакт», отказы, глубина, доля мобильных конверсий, органический трафик из Яндекса и Google, позиции и CTR по ядру запросов, число страниц в индексе, Core Web Vitals (Lighthouse/PSI до и после).

## 6. SEO

**Техника**
- Корректные `sitemap.xml` (с разбивкой на индексы) и `robots.txt`. 301 с `www` на основной домен, HTTPS, canonical на каждой странице.
- Уникальные title и description на всех страницах. Для товаров — шаблон из характеристик: «Морозильный ларь Haier GTS1850G 549 л — купить в Твери, цена | ХолодМаркет».
- Один H1 на страницу, логичная иерархия H2/H3, хлебные крошки.
- Микроразметка Schema.org: `Organization` + `LocalBusiness` (адрес, телефоны, часы, координаты), `Product` + `Offer` (цена в RUB), `BreadcrumbList`, `Service` для услуг, `FAQPage`, где есть вопросы.
- OpenGraph и Twitter-карточки (красивое превью в мессенджерах — важно, ссылками тут делятся часто).
- **YML-фид для Яндекса** (раздел «Товары и цены» в Вебмастере): бесплатный показ товаров в поиске и на Маркете-выдаче — очень подходит для информационного каталога.
- IndexNow (Яндекс) при обновлениях. Alt у всех изображений. Lighthouse 95+ на мобильных.

**Семантика** (проверить и расширить по Wordstat). Ядро: «холодильное оборудование Тверь», «торговое оборудование Тверь», «морозильный ларь купить Тверь», «холодильная витрина / горка / шкаф купить Тверь», «бонета», «оборудование для общепита / пекарни Тверь», «ремонт холодильного оборудования Тверь», «обслуживание холодильного оборудования», «монтаж холодильного оборудования», «заправка фреоном», «весы торговые Тверь». Каждая категория и услуга — отдельная посадочная страница под свой кластер с уникальным вступительным текстом (2–4 абзаца, без воды) и FAQ.

**Локальное SEO:** карточки компании в Яндекс Бизнесе (Карты), 2ГИС и Google Business с единым NAP (название, адрес, телефон), отзывы, ссылка на сайт.

## 7. Изображения и ИИ

- **ИИ — для атмосферных изображений:** hero, обложки категорий, страницы услуг (монтаж, сервис), «О компании». Там генерация оправдана и сильно поднимает визуал.
- **Фото товаров ИИ не заменять.** Карточка должна показывать реальную модель, иначе это введение покупателя в заблуждение (и риск претензий). Вместо этого: удалить фон, привести к единому светлому фону и пропорциям, апскейлить слабые фото. Это можно делать автоматически и пакетно.
- Сертификаты и логотипы брендов — оригиналы.
